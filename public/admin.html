Cloudflare D1 & Architecture Checklist

This admin dashboard connects directly to Cloudflare D1 for persistent storage and uses salted SHA-256 password hashing stored in D1 (or optionally ADMIN_PASSWORD secret).

1. D1 Database Binding: Ensure D1 database binding variable is named DB in wrangler.jsonc.

2. Database Migration: Apply migrations/0001_initial_schema.sql via Cloudflare D1 console.

3. Admin Setup: Once deployed, initialize your password directly at ashabd.in/admin.
