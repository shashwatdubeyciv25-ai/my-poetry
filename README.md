# 🪶 काव्य-कुंज (Kavya-Kunj) — व्यक्तिगत हिंदी कविता वेबसाइट

> **"दिल के अल्फ़ाज़, रूह की ज़ुबाँ"**  
> एक सुरुचिपूर्ण, कलात्मक और आधुनिक हिंदी काव्य मंच (Personal Hindi Poetry Website)।

---

## ✨ मुख्य विशेषताएँ (Key Highlights)

- 🎨 **अति-सुंदर व कलात्मक डिज़ाइन (Aesthetic UI/UX)**:
  - शास्त्रीय देवनागरी टाइपोग्राफी (`Rozha One`, `Yatra One`, `Tiro Devanagari Hindi`, `Noto Serif Devanagari`)।
  - **तीन सुंदर थीम्स**:
    - **नूर (Parchment)**: विंटेज एंटीक काग़ज़ और गहरी स्याही।
    - **शब-ए-महफ़िल (Midnight Mushaira)**: मोमबत्ती और सितारों की रोशनी जैसी गहरी नाइट थीम।
    - **गुलाब (Sandalwood Rose)**: चंदन और गुलाब के हल्के पेस्टल शेड्स।

- 📜 **समृद्ध हिंदी काव्य संकलन (Rich Demo Poems Included)**:
  1. **ख़ामोशियों की सदा** (नज़्म • रूहानियत)
  2. **चाँद, चाय और वो रात** (ग़ज़ल • प्रेम)
  3. **कागज़ की कश्ती और बारिश** (कविता • यादें)
  4. **उम्मीद का चिराग़** (मुक्तक • हौसला)

- 🔍 **खोज व वर्गीकरण (Search & Filters)**:
  - विधाओं के अनुसार फ़िल्टर: नज़्म, ग़ज़ल, कविता, मुक्तक, और ❤️ पसंदीदा।
  - देवनागरी और हिंग्लिश/अंग्रेज़ी दोनों में तुरंत लाइव खोज।

- 🧘 **शांत पठन अनुभव (Zen Reader Modal)**:
  - बिना किसी ध्यान भटकाव के पूरी कविता का विस्तृत पठन।
  - **शब्दार्थ (Word Meanings / Glossary)**: कठिन उर्दू/हिंदी शब्दों पर क्लिक करके तुरंत अर्थ जानें।
  - **भावार्थ (Poetic Essence)**: कविता के मूल संदेश व प्रेरणा का सारांश।
  - **अक्षर आकार नियंत्रक (A- / A+)**: सुविधानुसार फ़ॉन्ट आकार बदलें।

- 🎙️ **आवाज़ में वाचन (Voice Recitation / Audio Reader)**:
  - ब्राउज़र की Web Speech API द्वारा हिंदी आवाज़ में भावपूर्ण काव्य पाठ सुनें।

- 📸 **शेर कार्ड जनरेटर (Aesthetic Card Exporter)**:
  - HTML5 Canvas द्वारा किसी भी कविता या शेर का हाई-रेज़ोल्यूशन इंस्टाग्राम/व्हाट्सएप स्टेटस कार्ड (PNG) 1-क्लिक में डाउनलोड करें।

- 🎵 **माहौल संगीत (Generative Ambient Soundscape)**:
  - बिना किसी बाहरी ऑडियो फ़ाइल के शुद्ध Web Audio API द्वारा रचित:
    - 🌧️ सौंधी बारिश की फुहारें (Soft Rain)
    - 🪕 शांतिदायक तानपुरा धुन (Meditative Tanpura Drone)

- ✍️ **नई कविता जोड़ें (In-Browser Poem Composer)**:
  - वेबसाइट पर सीधे "रचना लिखें" बटन दबाकर अपनी नई कविताएँ लिखें, जो आपके ब्राउज़र के `localStorage` में सुरक्षित रहेंगी।

## 🚀 वेबसाइट कैसे चलाएं (How to View & Run)

### 1. सीधे ब्राउज़र में खोलें
`index.html` फ़ाइल पर डबल-क्लिक करें, यह किसी भी आधुनिक ब्राउज़र (Chrome, Edge, Firefox, Safari) में तुरंत खुल जाएगी।

### 2. लोकल वेब सर्वर (वैकल्पिक)
टर्मिनल या PowerShell में यह कमांड चलाएं:
```bash
python -m http.server 8000
```
फिर ब्राउज़र में `http://localhost:8000` खोलें।

## 🌐 GitHub Pages पर लाइव कैसे करें (Publish to GitHub Pages)

1. इस रिपॉजिटरी को अपने GitHub खाते पर पुश करें:
   ```bash
   git add .
   git commit -m "feat: complete aesthetic Hindi poetry website"
   git push origin main
   ```
2. GitHub पर अपने Repo की **Settings** में जाएँ।
3. बाएँ मेनू से **Pages** पर क्लिक करें।
4. **Branch** में `main` और फ़ोल्डर में `/ (root)` चुनकर **Save** करें।
5. 1 से 2 मिनट में आपकी वेबसाइट `https://<your-username>.github.io/<repo-name>/` पर लाइव हो जाएगी!

## 📝 अपनी नई कविताएँ स्थायी रूप से कैसे जोड़ें (How to Add Poems in Code)

`poems.js` फ़ाइल खोलें और `poemsData` ऐरे में अपनी कविता इस फ़ॉर्मेट में जोड़ें:

```javascript
{
  id: "apni-kavita-ka-slug",
  title: "आपकी कविता का शीर्षक",
  transliteration: "Title in English",
  category: "ग़ज़ल", // नज़्म, ग़ज़ल, कविता, या मुक्तक
  tag: "प्रेम",
  date: "29 सितंबर 2026",
  readTime: "2 मिनट",
  excerpt: "कविता की शुरुआती दो पंक्तियाँ...",
  stanzas: [
    [
      "पहली पंक्ति,",
      "दूसरी पंक्ति।"
    ],
    [
      "दूसरे बंध की पहली पंक्ति,",
      "दूसरे बंध की दूसरी पंक्ति।"
    ]
  ],
  glossary: [
    { word: "कठिन शब्द", meaning: "उसका सरल अर्थ" }
  ],
  essence: "कविता का भावार्थ या संदेश।"
}
```
